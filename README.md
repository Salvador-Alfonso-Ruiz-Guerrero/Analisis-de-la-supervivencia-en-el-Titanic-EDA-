# Analisis-de-la-supervivencia-en-el-Titanic-EDA-
EDA y modelo de regresión logística aplicado al dataset del Titanic para analizar los factores que influyen en la supervivencia de los pasajeros. Incluye limpieza y exploración de datos, visualizaciones clave y construcción de un modelo predictivo para estimar la probabilidad de supervivencia.
